## Specification

**Task**: Fix the failing test `tests/test_fts.py::test_enable_fts_replace_handles_legacy_bracket_quoted_content_table`

**Spec ID**: 001

**Goal**: The `enable_fts(..., replace=True)` method fails when attempting to replace an FTS5 table created with bracket-quoted identifiers (e.g., `[books_fts]`, `content=[books]`). The root cause is that `detect_fts()` only recognizes double-quoted FTS table declarations, causing the old table to not be properly dropped during the replacement process, resulting in a "table already exists" error.

**Acceptance Criteria**:
- [x] The test `tests/test_fts.py::test_enable_fts_replace_handles_legacy_bracket_quoted_content_table` passes
- [x] No other tests regress
- [x] The fix handles both bracket-quoted (`content=[table]`) and double-quoted (`content="table"`) FTS table declarations
- [x] All pytest and linting checks pass

**Root Cause**: The `detect_fts()` method in `sqlite_utils/db.py` (line 2780) used a SQL LIKE pattern that only matched double-quoted content references (`content="{table}"`). When an FTS table is created with bracket notation (`content=[books]`), SQLite persists this original quoting style in the `sqlite_master.sql` column, causing the pattern to fail and the table detection to return `None`.

## Changes Made

**File**: `sqlite_utils/db.py` (line 2780)

**Change**: Updated the `detect_fts()` method's SQL LIKE pattern to recognize bracket-quoted content references.

```python
# Before (broken):
args = {
    "like": '%VIRTUAL TABLE%USING FTS%content="{}"%'.format(self.name),
    "like2": '%VIRTUAL TABLE%USING FTS%content="{}"%'.format(self.name),
    "table": self.name,
}

# After (fixed):
args = {
    "like": '%VIRTUAL TABLE%USING FTS%content=[{}]%'.format(self.name),
    "like2": '%VIRTUAL TABLE%USING FTS%content="{}"%'.format(self.name),
    "table": self.name,
}
```

The fix adds support for bracket-quoted content references in the `like` pattern, while maintaining support for double-quoted references in the `like2` pattern. This enables `detect_fts()` to find legacy FTS tables regardless of their quoting style.
