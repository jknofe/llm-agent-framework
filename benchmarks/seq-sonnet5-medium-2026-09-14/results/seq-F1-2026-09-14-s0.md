```
# Module map

Stack: pure Python 3.10+, stdlib sqlite3. Deps: click, click-default-group,
pluggy (plugin hooks), python-dateutil, sqlite-fts4, tabulate, pip.
Entry point: `sqlite-utils = sqlite_utils.cli:cli` (console script).

## Areas

- sqlite_utils/db.py (4279 LOC) - core library. `Database` (connection
  wrapper, table/view listing, attach, extensions), `Queryable` (shared
  query base), `Table(Queryable)` (create/insert/update/upsert/transform/
  extract/fts/convert/index/foreign-keys...), `View(Queryable)`. Exceptions:
  TransformError, AlterError, NoObviousTable, NoTable, NoView,
  BadPrimaryKey, NotFoundError, PrimaryKeyRequired, InvalidColumns,
  BadMultiValues. This is the library surface re-exported from
  sqlite_utils/__init__.py.
- sqlite_utils/cli.py (3556 LOC) - Click CLI, entry point `cli()` (line
  149). ~90+ subcommands (`@cli.command()`), e.g. tables, views, optimize,
  rebuild-fts, analyze, vacuum, dump, add-column, add-foreign-key(s),
  insert/upsert, transform, extract, convert, create-*, index-*, triggers,
  memory. Thin wrapper over sqlite_utils/db.py; formatting via
  output_options/load_extension_option decorators.
- sqlite_utils/migrations.py (126 LOC) - `Migrations` class: versioned
  migration runner used internally to evolve a Database's own metadata.
- sqlite_utils/utils.py (636 LOC) - shared helpers: type sniffing
  (`suggest_column_types`, TypeTracker/ValueTracker), row iteration
  (_CloseableIterator, RowsFromFileError/RowsFromFileBadJSON, RowError),
  `Format` enum, `UpdateWrapper`, NullProgressBar, CSV/JSON/TSV parsing
  helpers feeding CLI insert/upsert.
- sqlite_utils/hookspecs.py (18 LOC) + plugins.py (35 LOC) - pluggy-based
  plugin system (`hookimpl`/`hookspec`), lets external packages add CLI
  commands / register SQL functions.
- sqlite_utils/recipes.py (76 LOC) - small reusable conversion recipes
  usable from `convert`/`convert --code`.
- tests/ (55 files, 11915 LOC) - pytest suite, one test_*.py roughly per
  CLI subcommand or db.py feature area (test_create.py, test_cli.py,
  test_fts.py, test_extract*.py, test_gis.py, etc). conftest.py has
  shared fixtures. tests/ext.c is a C SQLite extension built for
  --load-extension tests (needs `gcc ext.c -fPIC -shared -o ext.so`).
  sniff/ subdir has sample data for type sniffing tests.
- docs/ - Sphinx docs (cli.rst, python-api.rst, cli-reference.rst,
  migrations.rst, plugins.rst, changelog.rst, tutorial.ipynb). Large rst
  files are `cog`-generated from source/CLI --help; edit source, then
  `cog -r` to regenerate, never hand-edit generated blocks.

## Glossary

- "recipe" - a small named conversion function in recipes.py, invokable
  from `sqlite-utils convert --code`.
- "sniff" - column type detection from CSV/TSV samples (utils.py
  TypeTracker/ValueTracker, tests/sniff/ fixtures).
- FTS = SQLite full-text search (rebuild-fts, enable-fts commands).
- "transform" (Table.transform / `sqlite-utils transform`) - rewrites a
  table's schema (column types/order/pk) by recreating the table.
- cog = docs code-generator (cogapp) that keeps docs/*.rst and README.md
  CLI help text in sync with actual --help output.
```
