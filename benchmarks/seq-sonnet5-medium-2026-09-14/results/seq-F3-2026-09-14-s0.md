```
# Module map

Stack: Python 3.10+, stdlib sqlite3 + click (CLI), pluggy (plugin hooks),
setuptools build. No async. Single package, no src/ layout.

## Areas
- sqlite_utils/db.py (4279 LOC) - core library: `Database`, `Queryable`,
  `Table`, `View` classes; schema introspection, insert/upsert/update/
  delete, transform (ALTER-TABLE workarounds), FTS, extract, lookup,
  m2m, indexes, foreign keys. Entry point for the Python API
  (`import sqlite_utils` -> `sqlite_utils.Database`).
- sqlite_utils/cli.py (3556 LOC) - CLI entry point: `sqlite-utils`
  console script (pyproject `[project.scripts]`), built on click; one
  `@cli.command()` per subcommand (tables, views, optimize, rebuild-fts,
  analyze, vacuum, dump, add-column, add-foreign-key(s), insert,
  upsert, etc). `sqlite_utils/__main__.py` just calls `cli()`.
  docs/cli-reference.rst / docs/cli.rst are the generated/authored
  reference; do not re-derive command list here.
- sqlite_utils/utils.py (636 LOC) - shared helpers: type suggestion/
  affinity, `rows_from_file` (CSV/TSV/JSON/etc ingestion), progress
  bars, TypeTracker/ValueTracker (schema inference), spatialite
  detection.
- sqlite_utils/migrations.py (126 LOC) - `Migrations` class: named,
  ordered schema-migration functions applied against a `Database`,
  tracked in an applied-migrations table.
- sqlite_utils/recipes.py (76 LOC) - small conversion helpers exposed
  for `--convert` recipes: parsedate, parsedatetime, jsonsplit.
- sqlite_utils/plugins.py + hookspecs.py - pluggy-based plugin system;
  hookspecs: `register_commands`, `prepare_connection`, and more (see
  hookspecs.py). docs/plugins.rst documents authoring plugins.
- tests/ (11915 LOC, 55 files) - pytest, one file per feature/command
  area (test_cli.py is the largest, 80K, covers many subcommands
  end-to-end via click's CliRunner). conftest.py has shared fixtures.
  tests/ext.c is a native SQLite extension built ad hoc in CI
  (`gcc ext.c -fPIC -shared -o ext.so`) for the `--load-extension`
  test path; not built by default.
- docs/ (17 files, sphinx/rst + cog-generated snippets) - authoritative
  user docs: cli.rst / cli-reference.rst (CLI), python-api.rst
  (library), plugins.rst, migrations.rst, changelog.rst. README.md
  sections are also cog-managed (`just cog`). Do not duplicate content
  here; point at these files.

## Glossary
- "transform" - sqlite_utils' workaround for SQLite's limited
  `ALTER TABLE`: rebuilds a table to change column types/order/pk etc.
- "extract" - pull one or more columns out into a separate lookup
  table, replacing them with a foreign key.
- "m2m" - many-to-many helper (creates/uses a join table).
- "recipe" - a small named conversion function usable via CLI
  `--convert` (see recipes.py).
- cog - doc-generation tool (`cogapp`) that keeps README.md/docs/*.rst
  code snippets in sync with real output; `just lint` checks it,
  `just cog` regenerates it.
```
