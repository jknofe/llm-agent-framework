## Goal
Add a `Table.rename_column(old, new)` method to `sqlite_utils/db.py` and a
matching `rename-column` CLI sub-command, mirroring the existing
`rename_table()` / `rename-table` pattern (which uses a plain `ALTER TABLE
... RENAME TO ...` and lets `sqlite3.OperationalError` propagate, with an
`--ignore` CLI flag). Renaming a column onto a name that already exists on
the table must raise and must leave the table's schema/data unchanged (SQLite
itself refuses `ALTER TABLE ... RENAME COLUMN` when the target name
collides, raising `sqlite3.OperationalError: duplicate column name: <new>`
without partially applying the change, so this falls out of using the native
`ALTER TABLE ... RENAME COLUMN` statement rather than the `transform()`
rebuild path).
