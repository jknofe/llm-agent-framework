```
# Module map

stack: Python >=3.10, stdlib sqlite3 + click (CLI) + pluggy (plugin hooks).
setuptools build, packaged as `sqlite-utils` (console script: `sqlite-utils`).

## Areas
- sqlite_utils/db.py (4279 LOC) - core library. `Database` (connection
  wrapper, top-level API), `Queryable` base, `Table(Queryable)`,
  `View(Queryable)` - the public object model. Exceptions:
  TransformError, AlterError, NoObviousTable, NoTable, NoView,
  BadPrimaryKey, NotFoundError, PrimaryKeyRequired, InvalidColumns,
  BadMultiValues. Helpers: quote_identifier, jsonify_if_needed,
  resolve_extracts.
- sqlite_utils/cli.py (3556 LOC) - Click CLI, entry point
  `sqlite_utils.cli:cli` (console script `sqlite-utils`), one command
  per subcommand (create-table, insert, query, transform, etc); thin
  wrapper over db.py.
- sqlite_utils/__main__.py - `python -m sqlite_utils` -> cli.cli.
- sqlite_utils/hookspecs.py - pluggy hookspecs: `register_commands` (add
  CLI subcommands), `prepare_connection` (mutate sqlite3.Connection,
  e.g. register SQL functions). Plugin entry point group:
  "sqlite_utils".
- sqlite_utils/plugins.py - pluggy PluginManager setup;
  `ensure_plugins_loaded`, `get_plugins`.
- sqlite_utils/migrations.py (126 LOC) - `Migrations` class, `__init__`
  export.
- sqlite_utils/utils.py (636 LOC) - shared helpers incl.
  `suggest_column_types` (public, re-exported).
- sqlite_utils/recipes.py (76 LOC) - small reusable data-transform
  recipes.
- tests/ (52 files, 11915 LOC) - pytest, one file per feature/command
  (test_cli*.py for CLI, test_create.py/test_transform.py/test_fts.py
  etc for db.py features). tests/conftest.py has shared fixtures.
  tests/ext.c compiled by CI for --load-extension coverage.
  tests/sniff/ - fixture data for encoding/dialect sniffing tests.
- docs/ - Sphinx + cog-generated .rst: cli.rst / cli-reference.rst (CLI
  reference, cog-generated from --help), python-api.rst (library API
  reference), tutorial.ipynb, migrations.rst, plugins.rst,
  contributing.rst (dev workflow, source of truth for commands).
- .github/workflows/ - test.yml (matrix test+mypy+flake8+ty+black+cog
  check), test-coverage.yml, test-sqlite-support.yml, codeql-analysis,
  spellcheck, documentation-links, publish (PyPI release on tag).

## Glossary
- "sniff" - encoding/dialect detection for `insert --csv`/`--tsv` etc
  (see tests/test_sniff.py, tests/sniff/).
- "recipes" - small named transform functions usable from `--convert`.
- "extract"/"extracts" - normalizing a column's values into a lookup
  table (extract() on Table).
- "m2m" - many-to-many table helpers.
- "FTS" - SQLite full-text search integration (fts.py logic lives in
  db.py, tests in test_fts.py).
- "upsert" - insert-or-update by primary key.
- plugin hook "register_commands" lets third-party packages add
  `sqlite-utils <name>` subcommands; "prepare_connection" lets them
  register custom SQL functions.
```
